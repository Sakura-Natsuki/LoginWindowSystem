## 一、扩展功能概述

在原项目（登录 + 主控面板）的基础上，新增以下 3 个功能：

| 功能 | 说明 | 对应新文件 |
|------|------|-----------|
| **日志服务** | 全局单例，将用户操作记录到按日期命名的 `.log` 文件中 | `Services/LogService.cs` |
| **用户注册窗口** | 新用户输入用户名、密码、昵称完成注册，写入数据库 | `Views/RegisterWindow.xaml/.cs`、`ViewModels/RegisterViewModel.cs` |
| **主面板用户列表** | 登录后在主控面板中通过 DataGrid 展示所有已注册用户 | 修改现有 MainWindow.xaml / MainViewModel.cs |

## 二、涉及的技术栈

> 每个功能对应工作中常见的 WPF / C# 开发知识点。

| 技术点 | 出现位置 | 典型工作场景 |
|--------|---------|-------------|
| **单例模式 (Singleton)** | `LogService` | 全局日志、配置管理、数据库连接池 |
| **线程安全 (lock)** | `LogService` 写入、单例创建 | 多线程写文件、并发请求处理 |
| **文件 I/O** | `LogService` | 日志记录、配置文件读写、数据导出 |
| **ObservableCollection** | `MainViewModel` 用户列表 | 列表数据的动态增删改、DataGrid 绑定 |
| **DataGrid 控件** | `MainWindow.xaml` | 企业级数据展示、表格编辑、排序/筛选 |
| **密码确认校验** | `RegisterViewModel` | 表单验证、用户输入校验 |
| **数据库 INSERT** | `DatabaseService.RegisterUser()` | 注册、新增记录、数据写入 |
| **窗口导航** | Login→Register→Main 窗口切换 | 多窗口应用、导航模式 |
| **App.config 读取** | `LogService` 可扩展 | 配置管理、环境切换 |

### 5.1 Services/LogService.cs（日志服务）

**技术要点：** 单例模式（双重检查锁定）、lock 线程安全、文件 I/O

```csharp
using System;
using System.IO;
using System.Text;

namespace LoginWindowSystem.Services
{
    /// <summary>
    /// 全局日志服务（单例模式）。
    /// 使用方式：LogService.Instance.Info("消息内容");
    /// 日志文件存放于程序目录下的 Logs 文件夹，按日期命名。
    /// </summary>
    public class LogService
    {
        // ========== 单例相关 ==========

        // volatile：防止编译器对 _instance 的读写进行优化重排，
        //           确保所有线程看到的都是最新值
        private static volatile LogService _instance;

        // 用于双重检查锁定（DCL，Double-Check Locking）的锁对象
        private static readonly object _lock = new object();

        // 日志文件的完整路径（在构造函数中初始化）
        private readonly string _logPath;

        // ========== 构造函数 ==========

        /// <summary>
        /// 私有构造函数 —— 外部无法通过 new 创建实例，只能通过 Instance 属性获取。
        /// </summary>
        private LogService()
        {
            // 获取程序所在目录，例如 bin\Debug\
            string dir = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "Logs");

            // 如果 Logs 文件夹不存在则创建
            if (!Directory.Exists(dir))
                Directory.CreateDirectory(dir);

            // 日志文件名格式：2026-05-19.log
            _logPath = Path.Combine(dir, $"{DateTime.Now:yyyy-MM-dd}.log");

            // 写入一条启动日志，标记日志服务已初始化
            WriteRaw($"{new string('-', 40)}");
            WriteRaw($"日志服务启动 [{DateTime.Now:yyyy-MM-dd HH:mm:ss}]");
        }

        // ========== 单例访问点 ==========

        /// <summary>
        /// 全局唯一实例。
        /// 采用"双重检查锁定"（DCL）确保线程安全且性能良好：
        ///   - 第一次判空：大多数情况下 _instance 已初始化，直接返回，避免加锁开销
        ///   - lock：只有初始化阶段才加锁
        ///   - 第二次判空：防止多个线程同时通过第一次判空后排队进入 lock
        /// </summary>
        public static LogService Instance
        {
            get
            {
                // 第一次判空（无锁，性能高）
                if (_instance == null)
                {
                    // 加锁，同一时刻只有一个线程能进入
                    lock (_lock)
                    {
                        // 第二次判空（有锁保护，确保只 new 一次）
                        if (_instance == null)
                            _instance = new LogService();
                    }
                }
                return _instance;
            }
        }

        // ========== 公开的日志方法 ==========

        /// <summary>
        /// 记录普通信息日志，例如登录成功、注册成功。
        /// </summary>
        public void Info(string message)
        {
            WriteLog("INFO", message);
        }

        /// <summary>
        /// 记录错误日志，例如数据库连接失败、登录失败。
        /// </summary>
        public void Error(string message)
        {
            WriteLog("ERROR", message);
        }

        /// <summary>
        /// 记录警告日志，例如密码强度不足、权限不足。
        /// </summary>
        public void Warn(string message)
        {
            WriteLog("WARN", message);
        }

        // ========== 核心写入方法 ==========

        /// <summary>
        /// 写入带级别和时间戳的日志。
        /// lock 确保多线程同时写日志时不会出现内容交错。
        /// </summary>
        private void WriteLog(string level, string message)
        {
            // 格式示例：[2026-05-19 22:30:15] [INFO] 用户 admin 登录成功
            string line = $"[{DateTime.Now:yyyy-MM-dd HH:mm:ss}] [{level}] {message}";
            WriteRaw(line);
        }

        /// <summary>
        /// 直接写入文本行（不做格式化），用于分隔线等特殊内容。
        /// </summary>
        private void WriteRaw(string line)
        {
            // 加锁保证同一时刻只有一个线程在写文件
            lock (_lock)
            {
                // AppendAllText：以追加方式写入，如果文件不存在则自动创建。
                // Environment.NewLine：Windows 下为 \r\n
                File.AppendAllText(_logPath, line + Environment.NewLine, Encoding.UTF8);
            }
        }
    }
}
```

### 5.3 Views/RegisterWindow.xaml.cs（注册窗口后置代码）

**技术要点：** 窗口拖拽、PasswordBox 值同步、代码触发 ViewModel 命令

```csharp
using System.Windows;
using System.Windows.Controls;
using System.Windows.Input;

namespace LoginWindowSystem.Views
{
    /// <summary>
    /// RegisterWindow.xaml 的后置代码。
    /// 主要职责：
    ///   1. 支持无边框窗口拖拽
    ///   2. 将 PasswordBox 的值同步到 ViewModel（因为 PasswordBox 不支持绑定）
    ///   3. "返回登录" 超链接的事件处理
    /// </summary>
    public partial class RegisterWindow : Window
    {
        public RegisterWindow()
        {
            InitializeComponent();

            // 无边框窗口：鼠标左键按下时调用 DragMove() 实现拖拽
            MouseLeftButtonDown += (s, e) => DragMove();
        }

        /// <summary>
        /// 密码框内容变化时，将值同步到 RegisterViewModel.Password。
        /// PasswordBox 的 Password 属性是 CLR 属性而非依赖属性，
        /// WPF 无法对它进行数据绑定，因此需要此变通方案。
        /// </summary>
        private void PwdBox_PasswordChanged(object sender, RoutedEventArgs e)
        {
            // DataContext 在 XAML 中已设置为 RegisterViewModel 实例
            if (DataContext is ViewModels.RegisterViewModel vm)
            {
                vm.Password = PwdBox.Password;
            }
        }

        /// <summary>
        /// 确认密码框内容变化时，将值同步到 RegisterViewModel.ConfirmPassword。
        /// 原理与上面相同。
        /// </summary>
        private void ConfirmPwdBox_PasswordChanged(object sender, RoutedEventArgs e)
        {
            if (DataContext is ViewModels.RegisterViewModel vm)
            {
                vm.ConfirmPassword = ConfirmPwdBox.Password;
            }
```

### 5.4 ViewModels/RegisterViewModel.cs（注册窗口视图模型）

**技术要点：** 表单验证、密码确认、命令的 CanExecute 条件判断、async/await

```csharp
using LoginWindowSystem.Helpers;
using LoginWindowSystem.Services;
using System;
using System.Threading.Tasks;
using System.Windows;
using System.Windows.Input;

namespace LoginWindowSystem.ViewModels
{
    /// <summary>
    /// 注册窗口的 ViewModel。
    /// 职责：
    ///   1. 收集用户输入（用户名、密码、确认密码、昵称）
    ///   2. 前端验证（空值检查、密码一致性检查）
    ///   3. 调用 DatabaseService 写入数据库
    ///   4. 注册成功后跳转到 MainWindow
    /// </summary>
    public class RegisterViewModel : BaseViewModel
    {
        // ========== 服务依赖 ==========
        private readonly DatabaseService _db = new DatabaseService();

        // ========== 绑定属性 ==========

        private string _username;
        /// <summary>
        /// 用户名。绑定到用户名 TextBox。
        /// UpdateSourceTrigger=PropertyChanged 使得每次按键都更新。
        /// </summary>
        public string Username
        {
            get => _username;
            set => SetProperty(ref _username, value);
        }

        private string _password;
        /// <summary>
        /// 密码。由后置代码从 PasswordBox 同步过来。
        /// 注意：这不是绑定，而是手动赋值。
        /// </summary>
        public string Password
        {
            get => _password;
            set => SetProperty(ref _password, value);
        }

        private string _confirmPassword;
        /// <summary>
        /// 确认密码。与 Password 比较以确认用户输入无误。
        /// </summary>
        public string ConfirmPassword
        {
            get => _confirmPassword;
            set => SetProperty(ref _confirmPassword, value);
        }

        private string _nickname;
        /// <summary>
        /// 显示昵称。
        /// </summary>
        public string Nickname
        {
            get => _nickname;
            set => SetProperty(ref _nickname, value);
        }

        private string _errorMessage;
        /// <summary>
        /// 错误提示信息。不为空时自动显示在界面上（通过 StringToVisibilityConverter）。
        /// </summary>
        public string ErrorMessage
        {
            get => _errorMessage;
            set => SetProperty(ref _errorMessage, value);
        }

        private bool _isRegistering;
        /// <summary>
        /// 是否正在执行注册（防止重复提交）。
        /// 为 true 时注册按钮被禁用（通过 InverseBoolConverter）。
        /// </summary>
        public bool IsRegistering
        {
            get => _isRegistering;
            set => SetProperty(ref _isRegistering, value);
        }

        // ========== 命令 ==========

        /// <summary>
        /// 注册命令。点击 [注册] 按钮时执行。
        /// </summary>
        public ICommand RegisterCommand { get; }

        /// <summary>
        /// 返回登录命令。点击 [< 返回登录] 时执行。
        /// </summary>
        public ICommand BackToLoginCommand { get; }

        // ========== 构造函数 ==========

        public RegisterViewModel()
        {
            // 创建命令：
            //   第一个参数：点击时执行的方法
            //   第二个参数：返回 true/false 决定按钮是否可用
            RegisterCommand = new RelayCommand(async _ => await ExecuteRegister(), _ => CanRegister());
            BackToLoginCommand = new RelayCommand(_ => ExecuteBackToLogin());
        }

        // ========== CanExecute 判断 ==========

        /// <summary>
        /// 判断注册按钮是否可用。
        /// 条件：
        ///   1. 用户名、密码、确认密码、昵称均不为空或纯空格
        ///   2. 当前不在注册过程中（防止重复提交）
        ///
        /// 注意：此处仅做基本非空检查。
        /// 两次密码是否一致放在 Execute 中检查，
        /// 因为 CanExecute 只在焦点变化等特定时机触发，
        /// 不适合放过于复杂的验证逻辑。
        /// </summary>
        private bool CanRegister()
        {
            return !string.IsNullOrWhiteSpace(Username)
                && !string.IsNullOrWhiteSpace(Password)
                && !string.IsNullOrWhiteSpace(ConfirmPassword)
                && !string.IsNullOrWhiteSpace(Nickname)
                && !IsRegistering;
        }

        // ========== 命令执行方法 ==========

        /// <summary>
        /// 执行注册流程。
        /// async/await 模式确保 UI 不会在数据库操作期间卡死。
        /// </summary>
        private async Task ExecuteRegister()
        {
            // 1. 清空上次的错误信息
            ErrorMessage = string.Empty;

            // 2. 前端验证：两次密码必须一致
            if (Password != ConfirmPassword)
            {
                ErrorMessage = "两次输入的密码不一致";
                return; // 提前返回，不执行后续逻辑
            }

            // 3. 密码长度验证（至少6位）
            if (Password.Length < 6)
            {
                ErrorMessage = "密码长度至少为 6 位";
                return;
            }

            // 4. 设置"正在注册"状态，按钮变灰
            IsRegistering = true;

            try
            {
                // 5. 异步执行数据库操作
                //    Task.Run 将耗时操作放到线程池线程，避免阻塞 UI 线程
                bool success = await Task.Run(() => _db.RegisterUser(Username, Password, Nickname));

                if (success)
                {
                    // 6. 记录日志
                    LogService.Instance.Info($"新用户注册成功：{Username} ({Nickname})");

                    // 7. 注册成功 → 打开主控面板，关闭登录/注册窗口
                    var mainWin = new Views.MainWindow(Nickname);
                    mainWin.Show();

                    // 关闭注册窗口和登录窗口（如果还存在）
                    CloseWindow<Views.RegisterWindow>();
                    CloseWindow<Views.LoginWindow>();
                }
                else
                {
                    ErrorMessage = "注册失败：用户名已存在";
                    LogService.Instance.Warn($"注册失败（用户名已存在）：{Username}");
                }
            }
            catch (Exception ex)
            {
                // 8. 捕获所有异常（如数据库连接失败），显示给用户
                ErrorMessage = $"注册失败：{ex.Message}";
                LogService.Instance.Error($"注册异常：{ex.Message}");
            }
            finally
            {
                // 9. 无论成功或失败，都需要恢复按钮状态
                IsRegistering = false;
            }
        }

        /// <summary>
        /// 返回登录窗口。
        /// 关闭当前注册窗口，打开登录窗口。
        /// </summary>
        private void ExecuteBackToLogin()
        {
            LogService.Instance.Info("用户从注册页面返回登录");

            // 打开登录窗口
            new Views.LoginWindow().Show();

            // 关闭注册窗口
            CloseWindow<Views.RegisterWindow>();
        }

        // ========== 辅助方法 ==========

        /// <summary>
        /// 关闭指定类型的窗口。
        /// 通过泛型参数 T 指定要关闭的窗口类型。
        ///
        /// Application.Current.Windows 是当前应用程序中所有打开的窗口集合。
        /// 遍历它找到指定类型的窗口并关闭。
        /// </summary>
        private void CloseWindow<T>() where T : Window
        {
            foreach (Window w in Application.Current.Windows)
            {
                if (w is T)
                {
                    w.Close();
                    break; // 找到第一个后退出（通常只有一个该类型的窗口）
                }
            }
        }
    }
}
```

**新增方法 1：RegisterUser**

```csharp
        /// <summary>
        /// 注册新用户。
        /// 密码以 SHA256 哈希形式存储（与登录验证保持一致）。
        ///
        /// 返回值：true 表示注册成功，false 表示用户名已存在。
        /// </summary>
        /// <param name="username">用户名（唯一）</param>
        /// <param name="password">明文密码</param>
        /// <param name="nickname">显示昵称</param>
        public bool RegisterUser(string username, string password, string nickname)
        {
            // 1. 将明文密码转换为 SHA256 哈希（与登录时一致）
            string hash = Sha256(password);

            // 2. 创建数据库连接
            using (var conn = new SqlConnection(CONN_STR))
            {
                conn.Open();

                // 3. 先检查用户名是否已存在
                //    参数化查询：@u 是占位参数，避免 SQL 注入风险
                var checkSql = "SELECT COUNT(*) FROM Users WHERE Username = @u";
                using (var checkCmd = new SqlCommand(checkSql, conn))
                {
                    // AddWithValue 将 C# 变量的值安全地绑定到 SQL 参数
                    checkCmd.Parameters.AddWithValue("@u", username);

                    // ExecuteScalar 返回查询结果第一行第一列的值（此处为 COUNT 的值）
                    int count = (int)checkCmd.ExecuteScalar();

                    if (count > 0)
                    {
                        // 用户名已存在，返回 false
                        return false;
                    }
                }

                // 4. 执行 INSERT 插入新用户
                var insertSql = @"INSERT INTO Users (Username, PasswordHash, Nickname) 
                                  VALUES (@u, @p, @n)";
                using (var insertCmd = new SqlCommand(insertSql, conn))
                {
                    insertCmd.Parameters.AddWithValue("@u", username);
                    insertCmd.Parameters.AddWithValue("@p", hash);
                    insertCmd.Parameters.AddWithValue("@n", nickname);

                    // ExecuteNonQuery 用于 INSERT / UPDATE / DELETE，返回受影响的行数
                    int rows = insertCmd.ExecuteNonQuery();

                    // rows > 0 表示插入成功
                    return rows > 0;
                }
            }
        }
```

**新增方法 2：GetAllUsers**

```csharp
        /// <summary>
        /// 获取所有已注册用户列表。
        ///
        /// 返回值：List<UserModel>，按注册时间倒序排列（新用户在前）。
        ///        如果没有任何用户，返回空列表（不会返回 null）。
        /// </summary>
        public List<UserModel> GetAllUsers()
        {
            // 创建空列表 —— 即使数据库查询失败也返回空列表而不是 null
            var users = new List<UserModel>();

            using (var conn = new SqlConnection(CONN_STR))
            {
                conn.Open();

                // 按创建时间倒序：最新注册的用户排在最前面
                var sql = "SELECT Id, Username, PasswordHash, Nickname, CreatedAt FROM Users ORDER BY CreatedAt DESC";

                using (var cmd = new SqlCommand(sql, conn))
                {
                    // ExecuteReader：返回一个向前只读的数据流，适合读取大量数据
                    using (var r = cmd.ExecuteReader())
                    {
                        // Read() 每次调用前进到下一行，直到没有更多数据返回 false
                        while (r.Read())
                        {
                            // 将当前行的数据映射到一个 UserModel 对象
                            users.Add(new UserModel
                            {
                                Id = (int)r["Id"],
                                Username = (string)r["Username"],
                                PasswordHash = (string)r["PasswordHash"],
                                Nickname = (string)r["Nickname"],
                                CreatedAt = (DateTime)r["CreatedAt"]
                            });
                        }
                    }
                }
            }

            return users;
        }
```

### 5.9 ViewModels/MainViewModel.cs（添加用户列表逻辑）

**技术要点：** ObservableCollection 动态绑定、异步数据加载、命令复用

> **修改说明：** 添加 `Users` 属性（ObservableCollection），
> 添加 `LoadUsersAsync()` 方法，
> 修改 `RefreshCommand` 使其同时刷新时间和用户列表。

**完整修改后的 MainViewModel.cs 如下（标注了新增/修改的位置）：**

```csharp
using LoginWindowSystem.Helpers;
using LoginWindowSystem.Models;
using LoginWindowSystem.Services;
using System;
using System.Collections.ObjectModel;   // ← 新增 using
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using System.Windows;
using System.Windows.Input;

namespace LoginWindowSystem.ViewModels
{
    public class MainViewModel : BaseViewModel
    {
        // ========== 原有属性 ==========

        string _nickNmae;
        string _currentTime;
        string _welcomeMessage;

        public string Nickname
        {
            get => _nickNmae;
            set => SetProperty(ref _nickNmae, value);
        }

        public string CurrentTime
        {
            get => _currentTime;
            set => SetProperty(ref _currentTime, value);
        }

        public string WelcomeMessage
        {
            get => _welcomeMessage;
            set => SetProperty(ref _welcomeMessage, value);
        }

        // ========== 新增：用户列表属性 ==========

        /// <summary>
        /// ObservableCollection 与 List 的区别：
        ///   - List：内容变化不会自动通知 UI
        ///   - ObservableCollection：添加/删除元素时自动触发 CollectionChanged 事件，
        ///     DataGrid 收到事件后自动更新显示。
        ///
        /// 这是 WPF 数据绑定的核心机制之一。
        /// </summary>
        public ObservableCollection<UserModel> Users { get; set; }
            = new ObservableCollection<UserModel>();

        // ========== 命令（修改后） ==========

        public ICommand RefreshCommand { get; }

        public ICommand DisconnectCommand { get; }

        // ========== 构造函数（修改后） ==========

        public MainViewModel(string nickname)
        {
            Nickname = nickname ?? "Unknown";
            WelcomeMessage = $"欢迎回来, {Nickname}";

            UpdateTime();

            // 修改：RefreshCommand 同时刷新时间和用户列表
            RefreshCommand = new RelayCommand(async _ =>
            {
                UpdateTime();
                await LoadUsersAsync();
            });

            DisconnectCommand = new RelayCommand(_ => ExecuteDisconnect());

            // 新增：首次加载时异步获取用户列表
            // 使用 _ = 忽略返回值（fire-and-forget 模式），
            // 不需要等待加载完成再显示窗口。
            _ = LoadUsersAsync();

            // 记录日志
            LogService.Instance.Info($"用户 {Nickname} 进入主控面板");
        }

        // ========== 原有方法 ==========

        private void UpdateTime()
        {
            CurrentTime = DateTime.Now.ToString("yyyy HH:mm:ss");
        }

        private void ExecuteDisconnect()
        {
            LogService.Instance.Info($"用户 {Nickname} 断开连接");

            new Views.LoginWindow().Show();

            foreach (Window w in Application.Current.Windows)
            {
                if (w is Views.MainWindow)
                {
                    w.Close();
                    break;
                }
            }
        }

        // ========== 新增方法 ==========

        /// <summary>
        /// 异步加载用户列表。
        /// 从数据库获取所有已注册用户，填充到 ObservableCollection 中。
        ///
        /// 使用 async/await + Task.Run 模式：
        ///   - Task.Run 将数据库查询放到后台线程
        ///   - await 等待查询完成后回到 UI 线程更新集合
        ///   - 整个过程 UI 保持响应（不会卡顿）
        /// </summary>
        private async Task LoadUsersAsync()
        {
            try
            {
                var db = new DatabaseService();

                // Task.Run：将同步的数据库查询放到线程池中执行
                List<UserModel> list = await Task.Run(() => db.GetAllUsers());

                // 回到 UI 线程后更新 ObservableCollection
                // Clear + 逐个 Add 是最简单的方式
                Users.Clear();
                foreach (var user in list)
                {
                    Users.Add(user);
                }

                LogService.Instance.Info($"加载用户列表完成，共 {list.Count} 人");
            }
            catch (Exception ex)
            {
                // 加载失败不弹窗（因为这是后台操作），只记录日志
                LogService.Instance.Error($"加载用户列表失败：{ex.Message}");
            }
        }
    }
}
```

### 5.10 App.xaml.cs（初始化日志）

**技术要点：** 应用生命周期、启动时服务初始化

> **修改说明：** 在 `OnStartup` 中先初始化 LogService，再初始化数据库。
> 这样数据库初始化过程中的异常也能被日志记录。

**修改后的完整 App.xaml.cs：**

```csharp
using LoginWindowSystem.Services;
using System;
using System.Windows;

namespace LoginWindowSystem
{
    /// <summary>
    /// App.xaml 的交互逻辑。
    /// OnStartup 是 WPF 应用程序的入口点之一（另一个是 App 构造函数），
    /// 适合在窗口创建之前进行服务初始化。
    /// </summary>
    public partial class App : Application
    {
        protected override void OnStartup(StartupEventArgs e)
        {
            base.OnStartup(e);

            // ===== 新增：初始化日志服务 =====
            // LogService 是单例，首次访问 Instance 时会触发构造函数，
            // 自动创建 Logs 目录和当天的日志文件。
            // 放在最前面是为了确保后续所有操作都能被记录。
            try
            {
                LogService.Instance.Info("===== 应用程序启动 =====");
            }
            catch
            {
                // 日志初始化失败不应阻止应用启动
            }

            // ===== 原有：初始化数据库 =====
            try
            {
                new DatabaseService().InitDatabase();
                LogService.Instance.Info("数据库初始化完成");
            }
            catch (Exception ex)
            {
                // 新增日志记录
                LogService.Instance.Error($"数据库初始化失败：{ex.Message}");
                MessageBox.Show($"数据库初始化失败：{ex.Message}",
                                "WARNING", MessageBoxButton.OK, MessageBoxImage.Warning);
            }
        }
    }
}
```

### 5.11 LoginWindowSystem.csproj（注册新文件）

> 由于本项目使用旧版 .csproj 格式（非 SDK 风格），新增的 `.cs` 和 `.xaml` 文件需要**手动**在 `.csproj` 中注册，否则编译器不会编译它们。

在 `<ItemGroup>` 中按文件类型添加以下条目：

```xml
  <!-- ===== 新增：注册相关 ===== -->
  <ItemGroup>
    <!-- ViewModel -->
    <Compile Include="ViewModels\RegisterViewModel.cs" />

    <!-- Service -->
    <Compile Include="Services\LogService.cs" />

    <!-- View: XAML + 后置代码 -->
    <Page Include="Views\RegisterWindow.xaml">
      <Generator>MSBuild:Compile</Generator>
      <SubType>Designer</SubType>
    </Page>
    <Compile Include="Views\RegisterWindow.xaml.cs">
      <DependentUpon>RegisterWindow.xaml</DependentUpon>
    </Compile>
  </ItemGroup>
```

> **提示**：如果使用 Visual Studio，通过"添加 → 新建项"创建的文件会自动在 `.csproj` 中注册，无需手动编辑。
> 但如果是手动创建 `.cs` / `.xaml` 文件再添加到项目中，则需要右键 → "包括在项目中"。
> 此处列出 `.csproj` 的修改是为了让你了解背后发生了什么。
